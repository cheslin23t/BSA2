2022 Archived troop software

The RSVP system behind troop trips.

I initially built BSA2 for my Boy Scout troop’s website. It became the primary way scouts and families responded to trip invitations, while organizers got a simple view of who was and was not attending.

The original flow

One small system, built around a real need.

The project connected a public trip response form to a lightweight organizer view. It was early work, but it replaced an informal process with one shared source of attendance information.

  1. 01

    Response intake

    Families answered once.

    Name, contact details, trip, and a clear yes-or-no RSVP.
  2. 02

    Replit key/value data

    Responses stayed grouped by trip.

    Each submission joined the attending or not-attending list.
  3. 03

    Organizer view

    Trip rosters became visible.

    Leaders could review both lists from a server-rendered page.

What the code shows

An early operational Flask project.

BSA2 used Flask routes and templates with Replit’s database. It is preserved as evidence of progression—not presented as a current, secure, or deployable service.

  • Python + Flask
  • Server-rendered templates
  • Replit key/value storage
  • Archived, not maintained
